# 🚀 Как начать?

- Форкните репозиторий на GitHub.

- Клонируйте свой форк:
```sh
git clone https://github.com/<YourNickname>/Melomash.git
```

- Установите зависимости:
```sh
npm install
```

- Создайте ветку для своей задачи:
```sh
git checkout -b feature/<название-функции>
# или
git checkout -b fix/<описание-бага>
```

# 🛠 Правила разработки

### Добавление нового сервиса

Если вы хотите добавить новый музыкальный сервис, внесите изменения в массив `SERVICES` в файле `src/App.tsx`:

- Выберите подходящую иконку из lucide-react.

- Убедитесь, что URL сервиса поддерживает встраивание.

- Проверьте работу звука (автовоспроизведение).

### Код и стиль

- Мы используем TypeScript для надежности. Старайтесь избегать типа any.

- Для стилизации используется Tailwind CSS.

- При создании новых компонентов используйте useTheme(), чтобы они поддерживали смену тем (светлая/темная) и акцентные цвета.

- Для получения цвета акцента используйте функцию `getAccentColorClass`.

### AdBlock

Проект использует два уровня блокировки:

- Сетевой уровень (main.ts): Список паттернов в `AD_BLOCK_PATTERNS`.

- Косметический уровень (App.tsx): Переменная `COSMETIC_AD_BLOCK_CSS`, которая внедряется в webview для скрытия визуальных элементов рекламы.

- Перед коммитом убедитесь, что приложение успешно собирается:
```sh
npm run build
```

# 📮 Как отправить изменения?

- Запушьте ветку в свой форк:
```sh
git push origin feature/название-функции
```

- Откройте Pull Request (PR) в основной репозиторий.

  - В описании PR четко укажите:

    1. Что именно было изменено или исправлено.

    2. Скриншот (если изменился интерфейс).

    3. Связанную задачу (Issue), если она есть.
